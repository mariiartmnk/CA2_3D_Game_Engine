A bit of an unsettling vibe 3D Environment made for an assignment in IADT Game Design.  
Wander around, check out the streets of the tiny village. But be aware of the monsters that hunt you. If they see you, run as fast as you can using Shift, but mind your stamina. 
You can also collect eyes. Just like that, like a souvenir. 
The escape menu can bring you back to the game or out of it.

How to Play / Run

Playing 
1. Download the .zip package from https://immoosha.itch.io/unreal-environment
2. Extract the folder to your preferred location.
3. Run "Game_Engine.exe"
4. Make sure to not delete or mess with folders.

Opening in Unreal Engine
1. Make sure you have Unreal Engine 5.8 installed in the Epic Games Launcher.
2. Clone or download this repository:
   https://github.com/mariiartmnk/3D_Game_Engine
